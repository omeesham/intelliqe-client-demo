## Authentication

### 1. Verify successful login with valid credentials redirects to Dashboard
**Feature:** User Login · **Priority:** P0 · **Type:** positive

**Precondition:** A registered user account exists with username 'Admin' and password 'admin123'. The login page is reachable and the environment is qa.

**Steps:**

1. Navigate to https://opensource-demo.orangehrmlive.com/web/index.php/auth/login → Expected: Login page loads showing the OrangeHRM logo, Username field, Password field, Login button, and 'Forgot your password?' link
2. Enter 'Admin' into the field labelled 'Username' → Expected: Username field displays 'Admin' with no validation error
3. Enter 'admin123' into the field labelled 'Password' → Expected: Password field shows masked characters with no validation error
4. Click the 'Login' button → Expected: User is authenticated and redirected to the Dashboard page within 3 seconds; the URL contains '/dashboard' and the dashboard header is visible

**Expected Result:** User is authenticated, redirected to the Dashboard, and a valid authenticated session is established.

### 2. Verify login fails with valid username and invalid password showing generic error
**Feature:** User Login · **Priority:** P0 · **Type:** negative

**Precondition:** A registered user account exists with username 'Admin'. The login page is reachable.

**Steps:**

1. Navigate to https://opensource-demo.orangehrmlive.com/web/index.php/auth/login → Expected: Login page is displayed
2. Enter 'Admin' into the Username field → Expected: Username field displays 'Admin'
3. Enter 'WrongPass999' into the Password field → Expected: Password field shows masked characters
4. Click the 'Login' button → Expected: An 'Invalid credentials' error message is displayed; the message does not indicate whether username or password was wrong; the user remains on the Login page

**Expected Result:** Authentication fails, a generic 'Invalid credentials' error appears, and the user stays on the Login page.
